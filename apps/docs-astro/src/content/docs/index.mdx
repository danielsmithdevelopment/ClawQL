# ClawQL documentation

**ClawQL** is the secure, persistent MCP gateway for production agents — **`search`** and **`execute`** across OpenAPI, Discovery, and optional GraphQL/gRPC sources, with always-on **`audit`** and **`cache`**, optional vault memory, and defense-in-depth controls.

[Getting started](/getting-started) · [Quickstart](/quickstart) · [Architecture](/architecture) · [Deployment](/deployment)

---

## Agent-first operating system

Everything flows through one intelligent gateway. Components you leave off add no overhead. Official artifacts verify against **Layer 0 immutable releases**. Start with the [Vision & Roadmap](/vision/roadmap), then the [Master enablement guide](/vision/technical-enablement) for the full 6-layer architecture.
