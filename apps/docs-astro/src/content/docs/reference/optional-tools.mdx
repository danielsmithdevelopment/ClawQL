# Optional MCP tools

**ClawQL Core** always registers **`search`**, **`execute`**, **`audit`**, and **`cache`**. The tools below are optional — enable via **`CLAWQL_ENABLE_*`** env vars. Start with the **Learn walkthrough** for when to use each tool and composed recipes; use the cards below for deep dives.
