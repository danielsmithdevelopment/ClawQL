# ClawQL documentation

**ClawQL** is the secure, persistent MCP gateway for production agents — **`search`** and **`execute`** across OpenAPI, Discovery, and optional GraphQL/gRPC sources, with always-on **`audit`** and **`cache`**, optional vault memory, and defense-in-depth controls.

[Getting started](https://docs.clawql.com/getting-started) · [Quickstart](https://docs.clawql.com/quickstart) · [Architecture](https://docs.clawql.com/architecture) · [Deployment](https://docs.clawql.com/deployment)

---

## Agent-first operating system

Everything flows through one intelligent gateway. Components you leave off add no overhead. Official artifacts verify against **Layer 0 immutable releases**. Start with the [Vision & Roadmap](https://docs.clawql.com/vision/roadmap), then the [Master enablement guide](https://docs.clawql.com/vision/technical-enablement) for the full 6-layer architecture.
