## Headline (10 000 × 12 turns)

`combined = definitions + Σ discovery + Σ results`

| Arm | Definitions | Σ Discovery | Σ Results | Combined @12 | vs direct | Flow e2e p50 | RSS med |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| Direct HTTP (no MCP) | 5 520 | 0 | 29 482 | **35 002** | baseline | **2.2 ms** | — |
| **ClawQL (Bun)** | **297** | **11 568** | **8 674** | **20 539** | **−14 463** | 15.0 ms | 337 MB |
| **ClawQL (Node)** | **297** | **11 568** | **8 674** | **20 539** | **−14 463** | 18.2 ms | 678 MB |
| agentgateway | 5 520 | 0 | 29 482 | **35 002** | **match** | 13.6 ms | 214 MB |
| MCPJungle | 5 840 | 0 | 29 482 | 35 322 | +320 | 15.4 ms | **153 MB** |
| Executor | 90 | 0 | 53 578 | 53 668 | +18 666 | 64.4 ms | 213 MB |

ClawQL is the only measured gateway that **reduces** tokens vs a fair no-gateway baseline (projection + server-side discovery). Thin aggregators **match** that baseline — they do not invent an extra “schema tax.” Bun keeps those token wins and cuts Node’s multiturn RSS/p50 tax.

## Why Bun

Same `dist/server.js` — only the JS runtime changes. Pets board (TS7 rebuild): Ready RSS **−23%**, under-load **−25%**, gateway_cost p50 **−67%**. Chaos/p999 are not Bun wins; MCPJungle still leads RAM. Bun is the low-pain runtime track, not a Rust substitute.

## Reproduce

```bash
MT_TURNS=12 MT_ITERS=10000 CATALOG_TOOL_COUNT=40 \
  MT_ARMS=direct,clawql,clawql_bun,executor,mcpjungle,agentgateway \
  MT_OUT=gateway-multi-multiturn-10k.json \
  npm run benchmark:gateway-multi-multiturn

npm run generate:gateway-multi-page
```
