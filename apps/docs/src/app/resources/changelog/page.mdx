# Changelog & releases

ClawQL ships from the **`main`** branch with tagged releases on GitHub and npm publishes for **`clawql-mcp`**. **8.0.0** is the next major — provider opt-in empty catalog, **ProviderPlugin** hard break, and the last horizontal packages (`clawql-network`, `clawql-agents`, `clawql-audit`). {{ className: 'lead' }}

## Where to look

- **[GitHub Releases](https://github.com/danielsmithdevelopment/ClawQL/releases)** — tagged versions, release notes, and artifacts
- **[npm: clawql-mcp](https://www.npmjs.com/package/clawql-mcp)** — published MCP server package
- **[Vision & Roadmap](/vision/roadmap)** — honest shipped vs in-development matrix (updated between major releases)
- **[Migrate to 8.0](/getting-started/migrate-to-8.0)** — breaking changes from 7.x

## Versioning

- **Documentation** follows repo `main` — site MDX syncs from `docs/` at build time
- **Master enablement guide** is versioned in-document (currently **v2.1 · June 2026**)
- **Security curriculum** modules are tagged **May 2026** in frontmatter
- **Workspace `clawql-*` libraries** publish at **`0.1.0`** on first npm release with 8.0 (see repo `docs/release/`)
