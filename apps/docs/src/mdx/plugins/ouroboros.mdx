Plugin ID: clawql-harness (Ouroboros harness)

Packages: packages/clawql-harness — createOuroborosHarnessPlugin / makeHarnessLayer; library packages/clawql-ouroboros

Specification-first evolutionary loops with optional Postgres lineage storage. In clawql-mcp, agent-facing tools are **opt-in as of 8.0** — set `CLAWQL_ENABLE_OUROBOROS_TOOLS=1` or instance/tier `ouroboros.enabled: true`. Default **off** (no additive agent-loop proof yet). `CLAWQL_ENABLE_OUROBOROS` (old name) is deleted, not resurrected.
