Executor v1.6.10 — generous framing (verified)

Primary board arm is Executor v1.6.10 (stdio). Measured net vs baseline: +18,666. Split that fairly:

  • Code-mode definitions save 5,430 (5 520 → 90).
  • Pretty-printed results add 24,096 (53 578 − 29 482) — same data as the mock; indent tax only.
  • Net +18,666. Compacted ≈ 29 572 (−5 430 vs baseline). ClawQL still leads that by 9 033.

Discovery = 0: harness-authored execute returns the fixture (no search). Favors Executor vs ClawQL’s charged 11 568.

Where ClawQL’s next token win is

Discovery is 11,568 tokens — 56% of ClawQL’s combined total — about 964 search tokens/turn, larger than projected tool results (~723/turn). Projection already won Layer2; discovery is the next lever (no change to functionality):

  • Leaner search results — return compact typed signatures for top matches, not fuller entries. ~300 tok/turn (vs ~964) would cut ~8 000 from the 12-turn total.
  • Skip search when the agent already knows the operation — allow execute by operation ID directly when the same ops recur across turns, and measure how often the flow repeats operations.

How to read the trade

  • Direct HTTP — lowest latency, no gateway RSS; tokens = catalog definitions + fat bodies (fair agent baseline).
  • agentgateway / MCPJungle — match (or nearly match) that token total; fast multiplexers; they do not shrink Layer2.
  • ClawQL — only measured arm that reduces tokens vs the fair baseline (~14,463 @12, ~41%) via projection; pays discovery tokens + ~16.1 ms flow p50 and RSS. Untested: Bifrost, mcp-gateway.
  • Executor — defs save ~5.4k; pretty-print adds ~24k (net +18.7k measured / compacted −5.4k vs baseline). Discovery=0 by harness design (see above). Slowest flow p50 here.

3. Why move ClawQL from Node to Bun

Same dist/server.js and equal-arm env — only the JS runtime binary changes. Tokens are identical; Bun cuts the Node memory/latency tax without a Rust rewrite.

What not to claim

  • Do not say aggregators add a “schema tax” vs a zero-definition baseline — that baseline was unfair.
  • Do not say Executor invents extra payload fields — verified same data; excess is pretty-print formatting.
  • Do not claim “only gateway in the category that saves tokens” — this board has four gateways; Bifrost / mcp-gateway untested.
  • Do not link clawql.com/benchmarks/… until www Pages deploy includes this folder.
  • Do not mix topology-A ceilings with NATS 4-replica concurrency.
  • Do not hide ClawQL RSS; Bun shrinks it, Go-thin proxies still win RAM.
  • Token wins require task_success.
