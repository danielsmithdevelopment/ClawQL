# Pitch (say this on camera)

**One sentence:** Parallel agent attempts race on Artifacts forks; evidence decides the winner; the merge becomes an immutable, verifiable release.

**Fifteen seconds:** We fork a task three ways. Each attempt gets a repo-scoped token. Tests and policy write hash-chained git notes. One attempt is blocked for calling a host off the allowlist. A calibrated decision auto-merges only when confidence is high — otherwise a human approves. Then we ship a Merkle release to Arweave and canary at 10% on Workers. Anyone can verify.

**What is real in the local demo:** git forks, tokens, vitest, notes chain, Merkle verify, canary status file, live board.  
**What is dry-run until credentials:** Artifacts API / Turbo upload / Workers gradual deploy POST — same request shapes, labeled honestly.
