## Upgrading to 7.0.0

### Default provider merge (npm + Helm)

Before **7.0.0**, an empty spec environment often implied **`all-providers`**, and Helm chart values defaulted to **`all-providers`** as well. From **7.0.0** onward:

- Bare **`npx clawql-mcp`** loads the **opinionated default stack** (Cloudflare, GitHub, Slack, Linear, Notion, Onyx)
- Helm **`charts/clawql-mcp`** defaults to **`provider: default`** — same stack

Restore the full merge explicitly:

```bash
CLAWQL_PROVIDER=all-providers npx -p clawql-mcp clawql-mcp
```

```bash
helm upgrade --install clawql ./charts/clawql-mcp -n clawql --set provider=all-providers
```

Or use **`charts/clawql-idp/values-idp-full.yaml`** for the umbrella chart.

Local Docker Desktop / **`make local-k8s-up`** uses **`provider: default`** like npm. For a full IDP lab on Desktop:

```bash
make local-k8s-up HELM_EXTRA_SET='--set provider=all-providers'
```

### Vault-backed secrets (breaking default)

**`secretSourcing.requireVaultBackedSecrets`** is **`true`** by default. Helm render fails without **`envFromSecret`** / **`envFromSecrets`** pointing at a Kubernetes Secret (normally synced from HashiCorp Vault KV **`secret/clawql/providers`**).

```yaml
envFromSecret: clawql-provider-env
secretSourcing:
  requireVaultBackedSecrets: true # default — set false only for lab overlays
```

Before first pod schedule:

1. Install bundled Vault or point External Secrets at your cluster Vault.
2. Populate KV path **`secret/clawql/providers`** — [Vault provider secrets](https://github.com/danielsmithdevelopment/ClawQL/blob/main/docs/deployment/vault-provider-secrets.md).
3. Run **`make bootstrap-vault-eso`** on local stacks, or apply your ESO **`ExternalSecret`**.
4. Until sync succeeds, create a minimal placeholder **`Secret`** named **`clawql-provider-env`** so the Deployment can schedule.

**Lab opt-out (not for production):**

```yaml
secretSourcing:
  requireVaultBackedSecrets: false
```

You must then supply tokens via **`extraEnv`** or another supported pattern — plaintext cluster Secrets are discouraged.

Local stdio: use **`clawql init`** → **`~/.ClawQL/vault/providers.json`** — [local provider vault](https://github.com/danielsmithdevelopment/ClawQL/blob/main/docs/getting-started/local-provider-vault.md)

### Default-stack vault keys

When documents are **off** (`enableDocuments: false` or operator **`documents.enabled: false`**), populate at minimum:

| Vault property       | Env key                       |
| -------------------- | ----------------------------- |
| `githubToken`        | `CLAWQL_GITHUB_TOKEN`         |
| `slackToken`         | `CLAWQL_SLACK_TOKEN`          |
| `linearApiKey`       | `LINEAR_API_KEY`              |
| `notionApiToken`     | `NOTION_API_TOKEN`            |
| `onyxApiToken`       | `ONYX_API_TOKEN`              |
| `cloudflareApiToken` | `CLAWQL_CLOUDFLARE_API_TOKEN` |

When **documents / IDP** are on, also set Paperless, Stirling, Docling, and Nextcloud keys — full catalog in [vault-provider-secrets.md](https://github.com/danielsmithdevelopment/ClawQL/blob/main/docs/deployment/vault-provider-secrets.md).

### Removed legacy env aliases

| Removed                        | Use                      |
| ------------------------------ | ------------------------ |
| `API_BASE_URL`                 | `CLAWQL_API_BASE_URL`    |
| `OPENAPI_SPEC_URL`             | `CLAWQL_SPEC_URL`        |
| `GOOGLE_DISCOVERY_URL`         | `CLAWQL_DISCOVERY_URL`   |
| `CLAWQL_PROVIDER=google-top50` | `CLAWQL_PROVIDER=google` |

### Operator auth reconciliation

If you use **`ClawQLInstance`**, install the operator scaffold and confirm **`ProviderSecretsReady`**:

```bash
helm upgrade --install clawql-operator ./charts/clawql-operator -n clawql-system --create-namespace
kubectl apply -f examples/operator/clawqlinstance-minimal.yaml -n clawql
clawql operator status
```

The operator checks **`clawql-provider-env`** (or **`spec.mcp.providerSecretName`**) against expected vault keys:

- **`documents.enabled: false`** — default-stack keys only
- **`documents.enabled: true`** — default stack plus all IDP provider keys

See [Operator Helm](https://github.com/danielsmithdevelopment/ClawQL/blob/main/docs/deployment/clawql-operator-helm.md).

### First run on a new machine

```bash
npx -p clawql-mcp clawql onboard --interactive
clawql doctor --smoke
```

### 7.0 upgrade checklist

1. Replace legacy env aliases in `.env`, Helm values, and CI secrets
2. Wire Vault → **`clawql-provider-env`** (or opt out explicitly for labs only)
3. Run **`clawql onboard`** or populate Vault KV for default-stack keys
4. **`helm upgrade`** with **`provider: default`** or **`all-providers`** as needed
5. Verify **`clawql doctor --smoke`** (local) or **`/healthz`** + **`search`** (cluster)
6. If using the operator: confirm **`ProviderSecretsReady=True`** on your **`ClawQLInstance`**

macOS Desktop (Electron) secrets + Agent Chat: [ClawQL Desktop](/getting-started/clawql-desktop).

## Upgrading clawql-mcp (general)

1. Check [GitHub Releases](https://github.com/danielsmithdevelopment/ClawQL/releases) for breaking changes
2. Update **`CLAWQL_*`** env vars if provider or feature-tier defaults changed — [Configuration reference](/spec-configuration)
3. For Kubernetes/Helm: bump image digest in values, run **`helm upgrade`**, verify **`/healthz`**
4. Re-run smoke tests: **`search`** on a known operation, **`execute`** dry path, vault **`memory_recall`** if enabled

## From other MCP servers

| From                   | To ClawQL                                                                                        |
| ---------------------- | ------------------------------------------------------------------------------------------------ |
| Raw OpenAPI in context | **`search`** + **`execute`** — specs stay on disk                                                |
| Single-vendor MCP      | Default stack or narrow preset — **`CLAWQL_BUNDLED_PROVIDERS=…`** · **`CLAWQL_PROVIDER=github`** |
| Full multi-vendor MCP  | **`CLAWQL_PROVIDER=all-providers`** (explicit opt-in)                                            |
| Custom tool servers    | Proxy via gateway or migrate to **`execute`** operations                                         |
| No vault memory        | Enable **`memory_ingest`** / **`memory_recall`** with Obsidian vault path                        |
