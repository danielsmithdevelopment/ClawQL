## Recommended path

1. [Quickstart](/quickstart) — `npx clawql-mcp` (default stack) and connect Cursor or Claude Desktop
2. [Agent setup](/agent-setup) — desktop onboarding, Cursor iOS Cloud Agents, local sandbox
3. [MCP clients](/mcp-clients) — stdio, HTTP, and auth token wiring
4. [Concepts](/concepts) — how **`search`** and **`execute`** save context
5. [Using search & execute](/learn/search-and-execute-mcp) — first hands-on lesson
6. [Deploy with Helm](/helm) — full stack via `make local-k8s-up` or `helm upgrade --install`

## Deployment options

| Path                | Best for                                    | Start here                                                                                    |
| ------------------- | ------------------------------------------- | --------------------------------------------------------------------------------------------- |
| **Local MCP**       | Evaluation, solo dev                        | [Quickstart](/quickstart) · [Agent setup](/agent-setup)                                       |
| **Tier 1 Compose**  | Full local IDP slice                        | [Phase 1 guide](/getting-started/phase-1-platform-guide)                                      |
| **Helm full stack** | Team K8s, IDP pipeline                      | [Kubernetes](/deployment/kubernetes) · [Helm](/helm)                                          |
| **Teams**           | Shared memory + observability               | [For teams](/getting-started/for-teams) · [Team vault sync](/getting-started/team-vault-sync) |
| **Agents**          | Desktop, iOS Cloud Agents, Seatbelt sandbox | [Agent setup](/agent-setup)                                                                   |
| **Managed hosts**   | AWS/GCP/Cloudflare VM tiers                 | [Golden host images](/getting-started/golden-host-images) — Packer bake + Pulumi provision    |
| **Operations**      | Upgrades, secrets, health                   | [Operations guide](/deployment/operations-guide)                                              |
