## Recommended path

1. [Quickstart](/quickstart) — `npx clawql-mcp` (default stack) and optional install options
2. [Agent setup](/agent-setup) — desktop onboarding, Cursor iOS Cloud Agents, local sandbox
3. [Inference setup](/getting-started/inference) — OpenAI-compatible `/v1`, BYOK providers, MCP + memory
4. [MCP clients](/mcp-clients) — stdio, HTTP, and gateway auth
5. [Concepts](/concepts) — how **`search`** and **`execute`** save context
6. [Using search & execute](/learn/search-and-execute-mcp) — first hands-on lesson
7. [Deploy](/deployment) — Helm / Kubernetes when you outgrow local MCP
