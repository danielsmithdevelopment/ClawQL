## Recommended path

1. [Quickstart](/quickstart) — `npx clawql-mcp` (default stack) and connect Cursor or Claude Desktop
2. [Agent setup](/agent-setup) — copy-paste prompt for guided first run
2. [MCP clients](/mcp-clients) — stdio, HTTP, and auth token wiring
3. [Concepts](/concepts) — how **`search`** and **`execute`** save context
4. [Using search & execute](/learn/search-and-execute-mcp) — first hands-on lesson
5. [Deploy with Helm](/helm) — full stack via `make local-k8s-up` or `helm upgrade --install`
