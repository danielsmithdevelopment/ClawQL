## Recommended path

1. [Quickstart](/quickstart) — `npx clawql-mcp` (default stack) and connect Cursor or Claude Desktop
2. [Agent setup](/agent-setup) — desktop onboarding, Cursor iOS Cloud Agents, local sandbox
3. [MCP clients](/mcp-clients) — stdio, HTTP, and auth token wiring
4. [Concepts](/concepts) — how **`search`** and **`execute`** save context
5. [Using search & execute](/learn/search-and-execute-mcp) — first hands-on lesson
6. [Deploy with Helm](/helm) — full stack via `make local-k8s-up` or `helm upgrade --install`

## Shipped since 7.0

Phase 1 exit is complete. Enable or evaluate these with the docs linked below:

| Capability                       | Enable / path                                                                  |
| -------------------------------- | ------------------------------------------------------------------------------ |
| **Gateway auth** (`clawql-auth`) | `CLAWQL_AUTH_MODE=apiKey` — [MCP clients](/mcp-clients#gateway-api-key-auth)   |
| **PageIndex** (`pageindex_*`)    | Default on — [Memory plugin](/plugins/memory) · [clawql-memory](/learn/memory) |
| **Presidio hooks**               | `CLAWQL_ENABLE_PRESIDIO=1` — [MCP clients](/mcp-clients#presidio-redaction)    |
| **Tier 1 Compose**               | `examples/clawql-local-docker-compose`                                         |
| **Release manifest**             | [Release manifest (Layer 0)](/getting-started/clawql-release-mvp)              |
| **Default providers + Vault**    | [Migration guide](/resources/migration)                                        |

OIDC/SAML/RBAC beyond gateway API keys, full Operator NL ops, and vertical packages remain **roadmap** — [Vision & Roadmap](/vision/roadmap). Package-level ground truth: [modularization-implementation-status.md](https://github.com/danielsmithdevelopment/ClawQL/blob/main/docs/design/modularization-implementation-status.md).
