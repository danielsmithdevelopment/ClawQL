## Start here

If you are new to ClawQL, follow this sequence:

1. [Quickstart](/quickstart) — run the MCP server and connect a client in minutes
2. [Install](/install) — binaries, Docker, and Streamable HTTP
3. [MCP clients](/mcp-clients) — Cursor, Claude Desktop, and other MCP hosts
4. [Concepts](/concepts) — how **`search`** and **`execute`** fit together
5. [Using search and execute](/learn/search-and-execute-mcp) — **`search`** / **`execute`** inputs, args, fields, and pitfalls
6. [Tools](/tools) — full tool surface and behavior
7. [OpenClaw with ClawQL](/learn/openclaw-and-clawql) — gateway + **`openclaw mcp set`** + smoke path
