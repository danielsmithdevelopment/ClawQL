# Deployment & Operations

Choose a **deployment tier** that matches your environment. All tiers use the same MCP surface (`search` / `execute`); higher tiers add isolation, multi-tenancy, and enterprise controls. {{ className: 'lead' }}

<Note>
  **Full reference:** the [Deployment & Operations
  Guide](/deployment/operations-guide) is the authoritative Tier 1–3 document —
  CRD fields, auth, verticals, day-2 ops, and troubleshooting.
</Note>

## Choose your tier

| Question                                     | Tier 1 | Tier 2   | Tier 3   |
| -------------------------------------------- | ------ | -------- | -------- |
| Evaluating ClawQL or building locally?       | ✅     | —        | —        |
| Team-accessible shared deployment?           | —      | ✅       | —        |
| Multi-tenant isolation & regulated controls? | —      | Limited  | ✅       |
| Kubernetes required?                         | No     | Yes      | Yes      |
| Kata / gVisor runtime isolation?             | No     | Optional | Required |

If you are unsure, **start with Tier 1**. Configuration format is compatible enough that migrating to Tier 2 later does not require relearning fundamentals.
