# ClawQL documentation

**ClawQL** provides the **Agentic Gateway** as the **Foundational Platform for Auditable Production AI** — OpenAI-compatible inference and MCP **`search`** / **`execute`** across your APIs, with always-on **`audit`** and **`cache`**, optional vault memory, and defense-in-depth controls. Deploy as Regional Hubs, Dedicated Virtual Gateways, and Edge Gateways in a [Zero-Trust Agentic Fabric](/architecture/agentic-fabric). {{ className: 'lead' }}
