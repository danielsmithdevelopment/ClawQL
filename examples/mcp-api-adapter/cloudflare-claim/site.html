Checking your browser… almost.

This page stands in for a Cloudflare-style agent challenge. Instead of a human CAPTCHA, it publishes WebMCP tools agents can call to reveal and claim a coupon.

ClawQL’s Protocol Fabric indexes those tools, then /mcp-ui turns the claim step back into a one-click human button.

Waiting for WebMCP host… If your browser supports WebMCP, tools register automatically. For the ClawQL demo, the MCP mirror on :8093 is enough.
