# 7.0 observability profiles — implementation plan

**Tracking:** [#252](https://github.com/danielsmithdevelopment/ClawQL/issues/252) · **ADR:** [0005 Langfuse default work-trace store](../adr/0005-langfuse-default-work-trace-store.md) · **Target:** ClawQL **7.0.0**

This plan scopes the work to ship **observability profiles** with **Langfuse opt-out emission** and **profile-based backend deployment**. It does not require publishing npm or merging unrelated 7.0 items.

---

## Goals (7.0.0)

1. Operators get **working observability** in Tier 1 Compose without manual wiring.
2. **Langfuse** is the default **work-trace store** (token savings, eval scores, future synthetic export) — **opt-out**, not opt-in.
3. Teams with **existing stacks** use **`external`** profile — no bundled charts, same emission hooks.
4. **Seed auto-apply** from Langfuse eval remains **off by default** ([#250](https://github.com/danielsmithdevelopment/ClawQL/issues/250)).

## Non-goals (7.0.0)

- Full `clawql-telemetry` package extraction (modularization vision) — defer to 7.x follow-up.
- All roadmap Prometheus series (`clawql_mcp_tool_calls_total`, etc.) — keep dashboard roadmap doc.
- Langfuse Cloud SaaS coupling — self-host + BYO URL only.
- Automatic synthetic dataset export jobs — design hooks only (attributes + scores).

## Phase 1 — Configuration contract (MCP + docs)

**Effort:** Small — env parsing, docs, `.env.example`.

### 1.1 New environment variables

| Variable                       | Values                               | Default (by profile)                        |
| ------------------------------ | ------------------------------------ | ------------------------------------------- |
| `CLAWQL_OBSERVABILITY_PROFILE` | `bundled` \| `external` \| `minimal` | `external` if unset; Compose sets `bundled` |
| `CLAWQL_LANGFUSE_ENABLED`      | `1` / `0` / `auto`                   | `auto` → on unless disabled                 |
| `CLAWQL_DISABLE_LANGFUSE`      | `1`                                  | unset                                       |
| `LANGFUSE_HOST`                | URL                                  | bundled: `http://langfuse:3000`             |
| `LANGFUSE_PUBLIC_KEY`          | `pk-lf-...`                          | dev keys in Compose only                    |
| `LANGFUSE_SECRET_KEY`          | `sk-lf-...`                          | dev keys in Compose only                    |
| `CLAWQL_OTEL_COLLECTOR_URL`    | `http://otel-collector:4318`         | bundled auto                                |
| `CLAWQL_LOKI_PUSH_URL`         | URL or `auto`                        | bundled auto                                |

**Resolution rules (`auto`):**

- If `CLAWQL_DISABLE_LANGFUSE=1` → no Langfuse export.
- If `CLAWQL_OBSERVABILITY_PROFILE=minimal` → no Langfuse, no OTLP unless explicitly set.
- If `bundled` and Langfuse service DNS resolves → enable Langfuse OTLP exporter config.
- If `external` and `LANGFUSE_HOST` + keys set → enable; else log once at startup and continue.

### 1.2 Code touchpoints

| File                                                | Change                                                                  |
| --------------------------------------------------- | ----------------------------------------------------------------------- |
| `packages/clawql-api/src/config/optional-flags.ts`  | Parse profile + Langfuse flags                                          |
| `src/otel-tracing.ts`                               | Honor profile; optional second exporter or document collector-only path |
| New `src/langfuse-trace-export.ts` (or extend otel) | Langfuse OTLP endpoint + auth headers when enabled                      |
| `src/clawql-audit-loki.ts`                          | `CLAWQL_LOKI_PUSH_URL=auto` for bundled                                 |
| `.env.example`                                      | Document profile block                                                  |
| `dashboard/src/generated/env-catalog.json`          | Regenerate if CI requires                                               |

### 1.3 Span attributes (token savings foundation)

Extend `wrapMcpToolHandler` / audit correlation to set:

- `clawql.correlation_id`
- `clawql.tool_name`
- `clawql.planning_bytes` (when measurable on `search`)
- `clawql.token_savings_estimate` (when benchmark metadata available)

Document Langfuse score names: `token_savings_ratio`, `planning_efficiency`.

**Acceptance:** With `CLAWQL_OBSERVABILITY_PROFILE=bundled` and Langfuse up, MCP `search`/`execute` spans appear in Langfuse UI within 60s.

## Phase 2 — Tier 1 Compose `observability` profile

**Effort:** Medium — new compose services + wiring.

### 2.1 Add `examples/clawql-local-docker-compose/docker-compose.observability.yml` (or profile)

Services:

| Service          | Image / chart                                  | Notes                                                |
| ---------------- | ---------------------------------------------- | ---------------------------------------------------- |
| `otel-collector` | `otel/opentelemetry-collector-contrib`         | Fan-out: Tempo + Langfuse                            |
| `prometheus`     | `prom/prometheus`                              | Scrape MCP `/metrics`                                |
| `loki`           | `grafana/loki`                                 | Audit push target                                    |
| `tempo`          | `grafana/tempo`                                | Infra traces                                         |
| `grafana`        | `grafana/grafana`                              | Provision datasources + import `docs/grafana/*.json` |
| `langfuse`       | upstream compose or `langfuse/langfuse` + deps | Dev-sized; document resource needs                   |

### 2.2 MCP service env (bundled)

```yaml
CLAWQL_OBSERVABILITY_PROFILE: bundled
CLAWQL_ENABLE_OTEL_TRACING: "1"
OTEL_EXPORTER_OTLP_ENDPOINT: http://otel-collector:4318
CLAWQL_LOKI_PUSH_URL: http://loki:3100/loki/api/v1/push
LANGFUSE_HOST: http://langfuse:3000
# Dev keys from compose secrets / .env.example
```

### 2.3 Opt-out paths

```bash
# Lightweight — no Langfuse container
CLAWQL_DISABLE_LANGFUSE=1 docker compose --profile observability up

# Metrics only
CLAWQL_OBSERVABILITY_PROFILE=minimal docker compose up
```

### 2.4 Collector config

New file: `docker/observability/otel-collector-bundled.yaml`

- Receivers: `otlp`
- Exporters: `otlp/tempo`, `otlphttp/langfuse` (with Basic auth from env)
- Processors: `memory_limiter`, `batch`, optional `filter` for Langfuse (LLM-relevant spans)
- Self-metrics on `:8888`

**Acceptance:** `./bootstrap.sh && docker compose --profile observability up` → Grafana, Langfuse, and MCP traces visible; `CLAWQL_DISABLE_LANGFUSE=1` skips Langfuse UI data but Tempo still works.

## Phase 3 — Helm profiles

**Effort:** Medium–large — values files; optional `charts/clawql-observability` umbrella.

### 3.1 Values structure

```yaml
# charts/clawql-mcp/values.yaml (excerpt)
observability:
  profile: external # bundled | external | minimal

  langfuse:
    enabled: true # emission default; bundled subchart toggle
    disableEmission: false # maps to CLAWQL_DISABLE_LANGFUSE

  bundled:
    enabled: false
    otelCollector: { enabled: true }
    prometheus: { enabled: true }
    loki: { enabled: true }
    tempo: { enabled: true }
    grafana: { enabled: true }
    langfuse: { enabled: true }
```

Ship reference files:

- `charts/clawql-mcp/values-observability-bundled.yaml`
- `charts/clawql-mcp/values-observability-external.yaml`

### 3.2 External profile example

```yaml
observability:
  profile: external
  bundled:
    enabled: false

clawql-mcp:
  extraEnv:
    CLAWQL_OBSERVABILITY_PROFILE: external
    CLAWQL_ENABLE_OTEL_TRACING: "1"
    OTEL_EXPORTER_OTLP_ENDPOINT: "https://otel.corp.example:4318"
    LANGFUSE_HOST: "https://langfuse.corp.example"
    # keys from secret
```

### 3.3 Docker Desktop lab alignment

Update `charts/clawql-mcp/values-docker-desktop.yaml` commented `extraEnv` to match ADR 0005 when `observability.profile: bundled`.

**Acceptance:** `helm template` with bundled values renders collector + Langfuse subchart conditions; external values render MCP env only.

## Rollout and migration

> **Observability profiles (ADR 0005):** Tier 1 Compose ships optional bundled LGTM + Langfuse stack; Langfuse work-trace emission is opt-out in bundled/external profiles. Eval seed auto-apply unchanged (off by default).
