# Release checklist — v7.1.0

**Goal:** Tag and publish **`clawql-mcp@7.1.0`** after the remaining ontology PRs land and Docker publish is green.

## Before merge of this prep PR

1. **Land ontology follow-ups** (merge when green, in any order that stays conflict-free):
   - [#720](https://github.com/danielsmithdevelopment/ClawQL/pull/720) — essay gap-closure band A (feat)
   - [#718](https://github.com/danielsmithdevelopment/ClawQL/pull/718) — docs site Enterprise Ontology page
   - [#719](https://github.com/danielsmithdevelopment/ClawQL/pull/719) — essay gap-closure backlog doc (may merge into / with #720)
2. **Land Docker publish fix** [#740](https://github.com/danielsmithdevelopment/ClawQL/pull/740) ✅ merged. Confirm overnight or manual **Docker publish** builds **clawql-dashboard** (agent token cannot `workflow_dispatch`; run from Actions UI or wait for cron).
3. **Rebase** `cursor/release-7-1-0-prep-611b` onto `main` (or merge main in).
4. Fold any new Unreleased bullets from those PRs into **`CHANGELOG` `[7.1.0]`** (leave `[Unreleased]` empty or for 7.1.1+).
5. Confirm **`package.json` version === `7.1.0`** across workspace + Helm `appVersion`.
6. CI green on the release-prep PR; merge to `main`.

## Release day (on `main`)

```bash
# 1. Clean main
git checkout main && git pull origin main
git status   # clean
node -p "require('./package.json').version"   # 7.1.0

# 2. Annotated tag (triggers npm publish workflow on v*)
bash scripts/release/git-release-tag.sh --push

# 3. Watch publish
gh run list --workflow "npm publish" --limit 3
gh release create v7.1.0 --title "clawql-mcp 7.1.0" --notes-file RELEASE_NOTES_v7.1.0.md
# (or edit GitHub release body from docs/announcements draft §5)

# 4. Confirm npm + images
npm view clawql-mcp version   # 7.1.0
# Prefer a green Docker publish on the release SHA (or re-run workflow_dispatch)
gh run list --workflow "Docker publish" --limit 3
```

## After npm is live

1. Publish announcement copy from [`docs/announcements/announcement-drafts-v7.1.0.md`](../announcements/announcement-drafts-v7.1.0.md) (Medium / LinkedIn / HN / X).
2. Optionally close or retarget stale **#626** (7.0 announcement draft) — 7.0 GitHub/npm already shipped; use **7.1** drafts for “what’s next” messaging, or ship a short 7.0 retrospective separately.
3. Docs site deploy (usual `main` → docs pipeline).
4. Bump any public “current version” callouts on landing if hardcoded (prefer “latest” / dynamic).

## Out of scope for 7.1.0

- Separate npm publish of every `clawql-*` package (still OIDC link gated; `clawql-mcp` tarball may bundle).
- TypeScript 7 major (#651).
- Retiring clawql-release-mvp (#659) unless green and intentional.

## Rollback

- npm: publish prior `7.0.0` is immutable; document pin `@7.0.0` if needed.
- Git: do not delete `v7.1.0` lightly; cut `7.1.1` for fixes.
