# Release checklist — v8.0.0

**Goal:** Tag and publish **`clawql-mcp@8.0.0`** (semver-**major**).

## Before merge of this prep PR

1. Confirm **`package.json` version === `8.0.0`** on root `clawql-mcp` + Helm `appVersion` (`manifests/charts/clawql-mcp` **0.8.0**, operator **0.3.0**, IDP **0.2.0**). Workspace **`clawql-*`** libraries: **first publish `0.1.0`** ([`clawql-workspace-package-versioning.md`](./clawql-workspace-package-versioning.md)); run `node scripts/release/apply-package-npm-versions.mjs` before tag.
2. Confirm CHANGELOG **Breaking** covers: empty catalog, **ProviderPlugin** hard break (#999), enforcement default-off, ENABLE_*/instance composition.
3. Confirm `RELEASE_NOTES_v8.0.0.md` + [`docs/getting-started/migrate-to-8.0.md`](../getting-started/migrate-to-8.0.md) migration one-liners; inventory **~1836 commits / ~261 merge PRs** (as of 2026-10-02). Confirm **Breaking** covers product-surface purge (PageIndex/CodeGraph) + empty catalog / ProviderPlugin / enforcement.
4. Confirm boot warnings: empty catalog `BREAKING (8.0.0)`; no-enforcement **SECURITY WARNING**; legacy `CLAWQL_ENABLE_*` without instance JSON.
5. CI green on this PR; merge to `main`.
6. Confirm **`main` CI** green on the merge commit (do not tag on a red tip).
7. **Workspace first-publish:** run `node scripts/release/apply-package-npm-versions.mjs`; confirm `clawql-network`, `clawql-analytics`, `clawql-harness`, and other `clawql-*` at **`0.1.0`** per [`clawql-workspace-package-versioning.md`](./clawql-workspace-package-versioning.md).
8. Re-scan `gh pr list --state merged --base main` since `v7.2.0` (and since last prep refresh) if anything else lands before tag day.

## Blocking gate — MCP Events ChatGPT live pass

**Do not tag `v8.0.0` until this passes.** Protocol/unit tests are not a substitute.

1. Complete every item in [`docs/specs/mcp/mcp-events-chatgpt-checklist.md`](../specs/mcp/mcp-events-chatgpt-checklist.md) against a ChatGPT plugin-connected ClawQL MCP server running the **exact signed RC image** that will be tagged `v8.0.0` (record **image digest** on the checklist). A pass on a dev build does not count.
2. **All seven** events must each get a real producer trigger and a real ChatGPT delivery (especially `stream.changed` watched-field + volatile-only negative, and `schedule.paused` auth pause → Reconnect sources).
3. For every delivery (and required negative), record **event ID** + matching **WORM** (`mcp_events.delivery`) evidence on the checklist — sign-off must be verifiable afterward (_verify us, don't trust us_).
4. Record operator sign-off (name, UTC date, commit SHA, **image digest**, PASS) in that checklist or the release PR comment.
5. Confirm `events/list` names match the public contract: `stream.changed`, `document.processed`, `hook.blocked`, `budget.exhausted`, `schedule.completed`, `schedule.paused`, `notification.sent`.
6. After tagging, confirm the published `v8.0.0` image digest equals the RC digest recorded on the checklist.

## Release day (on `main`)

```bash
# 0. Blocking: ChatGPT live checklist signed off on the RC image digest
#    (docs/specs/mcp/mcp-events-chatgpt-checklist.md §0 + evidence columns)

# 1. Clean main
git checkout main && git pull origin main
git status   # clean
node -p "require('./package.json').version"   # 8.0.0

# 2. Annotated tag (triggers npm publish workflow on v*)
bash scripts/release/git-release-tag.sh --push

# 3. Watch publish
gh run list --workflow "npm publish" --limit 3
gh release create v8.0.0 --title "clawql-mcp 8.0.0" --notes-file docs/release/RELEASE_NOTES_v8.0.0.md

# 4. Confirm npm + images — digest must equal checklist §0 RC digest
npm view clawql-mcp version   # 8.0.0
npm view mcp-api-adapter version   # 0.1.0 (first publish)
npm view mcp-grpc-transport version   # 1.0.0
npm view clawql-network version   # 0.1.0 (if published this tag)
npm view clawql-analytics version   # 0.1.0 (if published this tag)
gh run list --workflow "Docker publish" --limit 3
crane digest ghcr.io/danielsmithdevelopment/clawql-mcp:8.0.0
# → must match the sha256 recorded on the ChatGPT checklist sign-off
```

## Out of scope for 8.0.0

- Soft-landing Helm `providers.pack: default` while npm stays empty (intentionally aligned empty).
- Restoring the legacy `Plugin` bridge.
- Full separate registry publish of every `clawql-*` if OIDC still gated (audit wedge + observability have their own cadences).
- Deprecating stale npm `clawql-ouroboros@0.1.1` beyond release-note callout.
- Full `clawql-streams` agent wake loop / `stream_subscribe` MCP tools (change-detection via schedule → `stream.changed` ships; the Streams package does not).
