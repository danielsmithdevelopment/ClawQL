# Release checklist — v8.0.0

**Goal:** Tag and publish **`clawql-mcp@8.0.0`** (semver-**major**).

## Before merge of this prep PR

1. Confirm **`package.json` version === `8.0.0`** across lockstep workspace + Helm `appVersion` (`charts/clawql-mcp` **0.8.0**, operator **0.3.0**, IDP **0.2.0**). Note: `clawql-observability` stays on **independent** cadence — **first npm publish `0.1.0`** ([`clawql-observability-versioning.md`](./clawql-observability-versioning.md)).
2. Confirm CHANGELOG **Breaking** covers: empty catalog, **ProviderPlugin** hard break (#999), enforcement default-off, ENABLE_*/instance composition.
3. Confirm `RELEASE_NOTES_v8.0.0.md` + [`docs/getting-started/migrate-to-8.0.md`](../getting-started/migrate-to-8.0.md) migration one-liners.
4. Confirm boot warnings: empty catalog `BREAKING (8.0.0)`; no-enforcement **SECURITY WARNING**; legacy `CLAWQL_ENABLE_*` without instance JSON.
5. CI green on this PR; merge to `main`.
6. Confirm **`main` CI** green on the merge commit (do not tag on a red tip).
7. Re-scan `gh pr list --state merged --base main` since `v7.2.0` (and since last prep refresh) if anything else lands before tag day.

## Release day (on `main`)

```bash
# 1. Clean main
git checkout main && git pull origin main
git status   # clean
node -p "require('./package.json').version"   # 8.0.0

# 2. Annotated tag (triggers npm publish workflow on v*)
bash scripts/release/git-release-tag.sh --push

# 3. Watch publish
gh run list --workflow "npm publish" --limit 3
gh release create v8.0.0 --title "clawql-mcp 8.0.0" --notes-file RELEASE_NOTES_v8.0.0.md

# 4. Confirm npm + images
npm view clawql-mcp version   # 8.0.0
npm view mcp-api-adapter version   # 0.6.0 (if localPackExtras publish succeeds)
npm view mcp-grpc-transport version   # 1.0.0
gh run list --workflow "Docker publish" --limit 3
```

## After npm is live

1. Publish announcement copy from [`docs/announcements/announcement-drafts-v8.0.0.md`](../announcements/announcement-drafts-v8.0.0.md).
2. Docs site deploy (usual `main` → docs pipeline).
3. Call out **provider opt-in**, **ProviderPlugin rewrite**, and **enforcement opt-in** in support / Discord / Slack (7.x → 8.0).

## Out of scope for 8.0.0

- Soft-landing Helm `providers.pack: default` while npm stays empty (intentionally aligned empty).
- Restoring the legacy `Plugin` bridge.
- Full separate registry publish of every `clawql-*` if OIDC still gated (audit wedge + observability have their own cadences).
- Deprecating stale npm `clawql-ouroboros@0.1.1` beyond release-note callout.

## Rollback

- npm: prior `7.2.0` remains installable; document pin `@7.2.0` if needed.
- Git: do not delete `v8.0.0` lightly; cut `8.0.1` for fixes.
