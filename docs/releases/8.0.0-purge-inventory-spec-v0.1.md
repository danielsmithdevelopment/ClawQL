# ClawQL 8.0.0 purge inventory spec v0.1

**Status:** draft for Cursor / human freeze  
**Related:** [`docs/getting-started/migrate-to-8.0.md`](../getting-started/migrate-to-8.0.md), [`docs/reference/clawql-plugin-registry.md`](../reference/clawql-plugin-registry.md), [`docs/benchmarks/pageindex-ab-eval-spec-v0.1.md`](../benchmarks/pageindex-ab-eval-spec-v0.1.md)

## Goal

8.0.0 is a house-cleaning release. Do **not** bundle a tool unless it has a very clear purpose. Cleanup also improves Decide routing (tool/skill twins already caused a v0.5 classifier miss: `mcp.memory_ingest` vs `skill.clawql-memory-ingest`) and shrinks image scan / sign / defend surface.

This spec defines **how** to inventory and decide. The first inventory table is seeded from the repo; **60-day call counts** and final purge tickets are filled from the call store before freeze.

## “Very clear purpose” test (all four required)

A tool (or ranker / hybrid switch) **stays bundled** only if it passes:

| #   | Criterion          | How to measure                                                                                                      |
| --- | ------------------ | ------------------------------------------------------------------------------------------------------------------- |
| 1   | **Unique job**     | Does something no other bundled tool does (document the nearest overlap).                                           |
| 2   | **Evidence**       | Measured task-completion gain **or** hard requirement (security, compliance, named integration) nothing else meets. |
| 3   | **Real usage**     | Agents call it — 60-day counts from the call / audit store.                                                         |
| 4   | **Worth carrying** | Dependencies + attack surface justified by 1–3.                                                                     |

**Defaults when data is missing:**

- Zero calls **and** no evidence → **purge** (or demote to optional out-of-tree plugin).
- In **prove-by-freeze** without a result by the freeze date → **leave the default bundle** (may remain opt-in plugin).
- Passes unique job + requirement but low usage → keep **opt-in** (`CLAWQL_ENABLE_*=1`), not default-on.

## Process

1. Regenerate inventory from code (not memory):
   - Flags: `packages/clawql-api/src/config/optional-flags.ts` + `.env.example` + memory-only gates (`CLAWQL_ENABLE_PAGEINDEX`, `CLAWQL_MEMORY_RECALL_HYBRID*`, `CLAWQL_MEMORY_VAULT_RANKER`).
   - Tools: every `ProviderPlugin` / `defineRegisteringProviderPlugin` `name:` registration under `packages/*/src/plugin/`.
   - Skills: `skills_list` index + handoff plugin.
2. Join **60-day call counts** per tool name (Loki / audit / inference call-store — pick one source of truth and cite it).
3. Fill columns: purpose, overlaps, eval evidence, calls_60d, decision (`keep` / `opt-in` / `prove` / `purge` / `consolidate`).
4. Open purge PRs that remove registration + flags + docs together; prefer optional plugins over silent retention.

## pageindex-ab linkage (do not re-litigate)

| Claim                                | Evidence                                         | Bundle implication                  |
| ------------------------------------ | ------------------------------------------------ | ----------------------------------- |
| RRF / merged PageIndex hurts default | 13–0 converted_pdf; displacement 13/13; p≈0.0002 | Not in omit-`sources` default       |
| Union +1.9 pts unproven              | 3 RFC wins; confound = larger k                  | Not a ship signal                   |
| BM25 wash                            | +1 Q                                             | No default ranker swap              |
| Agent-lite ≠ agent-loop              | Single retrieval, cheap model                    | `pageindex_*` tools still **prove** |
| Code “export X”                      | Grep hits gold files                             | CodeGraph must prove non-grep jobs  |

## Exit criteria for 8.0.0 freeze

- [ ] Full inventory table committed with `calls_60d` filled.
- [ ] Every **purge** row has a PR or explicit “optional plugin” home.
- [ ] Every **prove** row has a scored result **or** is removed from the default bundle.
- [ ] No tool/skill twin remains without a documented primary path.
- [ ] `.env.example` matches `optional-flags.ts` (no stale OUROBOROS enable; no silent missing flags).

## Out of scope

- Provider OpenAPI packs (empty catalog is already 8.0 default — pack selection is separate).
- Customer private plugins.
