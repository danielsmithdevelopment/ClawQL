# Durability comparison evidence (schema v2)

Generated by `npm run benchmark:durability-comparison`.

| File | Role |
| ---- | ---- |
| [`evidence.json`](./evidence.json) | Board run (arms × modes × trials) |
| [`manifest.json`](./manifest.json) | Tip package: columns, order, fleet tip links, superseded 0.4.0 rows, expansion pilots |

## Columns

Existing (unchanged meaning): `duplicates`, `outcomeUnknown` / completed-exactly-once reading, `lost`.

New (required on every arm):

| Column | Meaning |
| ------ | ------- |
| `runtime` / `runtimeVersion` | Shipped identity (e.g. `celld` / `0.6.3`) |
| `intentPresentOnResume` | System still knows a call was in flight after resume |
| `callVerifiedSent` | Call was in flight (or host-applied) before the kill |

## Tip runtime

Package pin: **stock celld 0.6.3**. Default board **N=50**. Pre-tip / 0.4.0 / clawql-fork / N=20 remasures are `superseded` in the manifest.

**Row identity:** `(armId, crashPhase)`. Wedged-owner and stale-owner are never folded into `during_call`.

**Peers:** every peer arm is present on the tip `harnessCommit` with the new columns; metrics are `null` and status `pending_adapter` until the peer adapter runs on this commit. Prefer N=50 pilots in the config-review package.
