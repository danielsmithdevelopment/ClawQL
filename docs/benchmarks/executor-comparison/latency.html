  • ClawQL arm is live MCP execute → local mock HTTP. Executor chart bar is a published warm 50–100ms reference (or, when wired, a no-op JS execute with no upstream). Not the same work.
  • Harness sets CLAWQL_CAPABILITY_LIFECYCLE=0 and optional tools off. MCP wrap still runs HookRegistry pre-hooks + ephemeral ring audit, but execute skips durable process WORM, WORM is not enabled, and there is no panguard-mcp-proxy / JWT-ATR sidecar hop.
