Honesty — Live Executor p50 3.256ms is faster than equalized ClawQL gateway overhead p50 7.414ms on this host.
  • Both arms return the same tiny pets JSON via one MCP execute. ClawQL goes through same-host mock HTTP; that cost is subtracted for the equalized overhead metric.
  • Executor is LIVE equal-arm MCP execute returning the same pets JSON.
  • Raw ClawQL execute e2e p50 7.9ms still includes same-host mock HTTP; equalized row subtracts it.
  • Do not use UsefulSoftwareCo/executor#1519 50–100ms as measured — wire EXECUTOR_BIN for live.
