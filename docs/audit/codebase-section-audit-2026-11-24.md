## Method

Every pass checks the same seven things, so findings from different passes can be compared and merged.

1. **Wrong:** bugs, broken links and paths, claims contradicted by code or evidence.
2. **Outdated:** anything superseded by decisions from the last few weeks, measured against the rules below.
3. **Fragmented:** the same thing in two or more places (docs, packages, configs, scripts) that should be one.
4. **Exposed:** stealth names, internal playbooks, secrets, personal or customer data, competitor commentary in public places.
5. **Default mismatch:** a feature described as on by default that ships off, or the reverse.
6. **Dead:** unused code, abandoned experiments, generated files checked in.
7. **Improve:** anything that would make it clearer, safer or easier to adopt.

**Rules every pass checks against (from recent decisions):**

- IDP means intelligent document processing only; platform-engineering features get another name.
- The ontology product is never named publicly; say "ClawQL's ontology layer" or "ClawQL's graph".
- "At most once" for approved writes, never "exactly once"; interrupted writes are "outcome unknown".
- celld fleet mode acknowledges on a disk quorum, before the bucket upload finishes.
- Claims only from measured or shipped evidence; no competitor jabs; quarantined numbers never cited as current.
- Hash-chained local WORM is **on by default** (8.0 / #1508); remote Object Lock defaults on Cloud paid tiers and the regulated profile; Panguard fail-closed remains opt-in — say so accurately wherever they're mentioned.
- No telemetry when self-hosted; pseudonymous data is never called anonymous; never read another application's credential files.
- No "FedRAMP-ready", "HIPAA certified" or "production deployments" without evidence.

**Finding format:** each pass adds a table with an ID (pass number and sequence, such as 1.04), severity, location, problem, change and effort.

- **Severity:** _Fix now_ means wrong, exposed or legally risky. _Before regulated launch_ means it blocks the day-one regulated pitch. _Cleanup_ means fragmentation, dead code or clarity.
- **Effort:** S (under an hour), M (a day or less), L (more).

Consolidation proposals get their own short list per pass, naming what merges into what and which copy wins.

**Decisions from review (2026-11-24):**

- **WORM on by default, in the 8.0.0 overhaul.** Hash-chained local WORM (SQLite or Postgres) runs by default in every edition. Remote durable copies with S3 Object Lock are the default on Cloud paid tiers and in the regulated profile. Turning WORM off needs an explicit setting, writes a final signed `WORM_DISABLED` entry first, warns at startup and reports the state on the health endpoint. In the regulated profile the gateway refuses to start with WORM off; leaving the profile is itself recorded. The agent-facing `audit` tool's `clear` empties only its view. Personal data stays out of the chain: hashes and references only, with per-person encryption keys that can be destroyed for erasure requests. Measure the overhead before release and publish it in the 8.0.0 notes. Code work goes to pass 3.
- **Ontology name:** scrub every current mention; no history rewrite, in keeping with the transparency commitment. Raw benchmark evidence files stay byte-identical; only displayed labels change. If asked: it was an early working name for ClawQL's ontology layer.
- **Homelab case study:** stays published; finding 0.14 is downgraded to cleanup.

**Status after #1508 (merged 2026-11-24, tip `ebb1c167` / fix head `829368a`):** fix-now items landed and CI is green. Remaining by design: the old name stays in raw evidence JSON and the evidence ID `ontologiql-rust` (compatibility), plus the constant `ONTOLOGIQL_PUBLISHABLE_ROW` in `packages/clawql-api/src/program/density/fair-board.ts`, which can be renamed without touching evidence. RPO=0 and FedRAMP wording survive in `apps/docs/src/generated/*` (Pass 9) until regenerated. The disaster-recovery curriculum's "RPO = 0" is a target and stays.

**Out of band (not fixable in the monorepo):** split `artifacts-attempts/` into its own repository; SSH keys only for `truenas_admin`; full Astro cutover and Next docs retirement; SQLite and S3 WORM latency (only in-process memory dual-ack was measured); anonymous MinIO for GitHub Actions once a pullable image exists again.
