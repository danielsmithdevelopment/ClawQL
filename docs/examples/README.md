| [`clawql-local-docker-compose/`](clawql-local-docker-compose/) | Tier 1 Compose                                         |
| [`mcp-api-adapter/`](mcp-api-adapter/)                         | Adapter demo server + PixelDrop                        |
| [`managed-gateway/`](managed-gateway/)                         | nginx edge in front of MCP + inference                 |

The docs site hub [`/examples`](https://docs.clawql.com/examples) is case-study walkthroughs, not a file browser for this folder.
